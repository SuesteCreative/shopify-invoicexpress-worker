Integração Cliente Novo (Admin Custom App) — Shopify → InvoiceXpress

Guia completo: criar Admin Custom App no admin do cliente, obter access token, e configurar o integrador Rioko. Versão sem Partner Dashboard / OAuth.

Aviso: Não partilhar tokens shpat_... nem Webhook Signing Secret por chat, email ou screenshots. Tratar como credenciais.

Parte A — Criar Admin Custom App no Admin do Cliente

App é criada dentro do admin Shopify do cliente (não no Partner Dashboard). Token é obtido directamente, sem OAuth code flow.

Pré-requisito: precisas de acesso ao admin do cliente como Store owner ou colaborador com permissão Develop apps. Pede ao cliente para te adicionar ou faz screen-share.

Passos no admin do cliente

  1. Login em https://{shop}.myshopify.com/admin com a conta do cliente.
  2. Settings (canto inferior esquerdo) → Apps and sales channels.
  3. Topo direito → Develop apps.
    • Se primeira vez na loja: clicar Allow custom app development → ler aviso → Allow custom app development novamente.
  4. Create an app → preencher:
    • App name: Rioko — InvoiceXpress (ou nome interno)
    • App developer: manter o utilizador actual
    → Create app.
  5. Tab Configuration → secção Admin API integration → Configure.
  6. Marcar os seguintes Admin API access scopes:
    • read_customers
    • read_discounts
    • read_order_edits
    • read_orders
    • read_products
  7. Ao marcar read_customers / read_orders, Shopify pede para aceitar Protected Customer Data Access:
    • Aceitar Level 1 (general customer data).
    • Aceitar Level 2 em Name, Email, Phone, Address — necessário para emitir faturas portuguesas com NIF e morada.
    • Justificação a colar quando pedida: "Portuguese fiscal invoicing (InvoiceXpress integration). Customer name, billing address and tax ID (NIF) are mandatory by AT (Autoridade Tributária) for legal invoice issuance under DL 28/2019."
  8. Save no topo direito.
  9. Tab API credentials → secção Access tokens → Install app → confirmar Install.
  10. Token shpat_... aparece uma única vez em Admin API access token. Clicar Reveal token once → copiar imediatamente para local seguro (1Password / cofre cliente).
O token só é mostrado uma vez. Se fechares a janela sem copiar, tens de desinstalar (tab API credentials → Uninstall) e reinstalar para gerar novo token.
Nota sobre read_all_orders: não disponível em Admin Custom Apps. Significa que o integrador só vê encomendas dos últimos 60 dias em backfill. Operação ongoing via webhooks não é afectada (dispara em tempo real). Para histórico anterior, importar via CSV diretamente no InvoiceXpress.
Domínio nativo: mostrado em Settings → Domains do admin (ex: quickstart-66f9e5ef.myshopify.com). Guardar — usado no Passo 1 do integrador.

Parte C — Webhook Signing Secret

  1. Shopify Admin (loja do cliente) → Settings → Notifications.
  2. Scroll até secção Webhooks.
  3. Procurar a frase: "Your webhooks will be signed with: ..."
  4. Copiar o secret.
Nota: Este secret é partilhado por todos os webhooks da loja — se já existirem outros webhooks, o secret é o mesmo.

Checklist resumido

  • Admin Custom App criada no admin do cliente (Settings → Apps → Develop apps).
  • Scopes correctos: read_customers, read_discounts, read_order_edits, read_orders, read_products.
  • Protected Customer Data Access Level 1 + Level 2 aceites pelo merchant.
  • App instalada e token shpat_... capturado.
  • Token testado com shop.json (HTTP 200).
  • Webhooks (orders/create + orders/updated + orders/paid + refunds/create) criados manualmente no Shopify.
  • Webhook Signing Secret introduzido no integrador.
  • IX conectado e ambiente correcto.
  • Definições fiscais ajustadas ao cliente.
  • Encomenda de teste validada end-to-end.

Parte F — Troubleshooting

Token perdido / não copiado a tempo

  • Token shpat_... só é mostrado uma vez em API credentials → Reveal token once.
  • Se perdido: tab API credentials → Uninstall app → confirmar → Install app novamente → novo token é gerado.
  • Desinstalar não apaga a app nem os scopes — só revoga o token.

Token inválido / HTTP 401 no integrador

  • Header tem de ser X-Shopify-Access-Token (Admin API).
  • Host tem de ser {shop}.myshopify.com exacto (não www., não domínio custom).
  • Usar Parte B para validar com shop.json antes de inserir no integrador.
  • Confirmar que a app está Installed no admin (tab API credentials mostra "App installed").

HTTP 403 ou scope em falta

  • Tab Configuration da app → confirmar todos os scopes marcados → Save.
  • Após alterar scopes: tab API credentials → secção Access tokens → clicar Reinstall app.
  • Reinstall não gera novo token — o existente fica válido com os novos scopes.
  • Se Protected Customer Data Access não foi aceite ao criar, voltar a Configuration → Configure → aceitar prompts → Save.

Backfill não encontra encomendas antigas

  • Admin Custom Apps não têm acesso a read_all_orders — só vêem os últimos 60 dias.
  • Para histórico anterior: importar via CSV diretamente no InvoiceXpress.
  • Webhooks ongoing não são afectados — disparam para todas as encomendas novas em tempo real.

Webhooks não disparam

  • Confirmar que os 4 webhooks estão criados em Settings → Notifications → Webhooks.
  • Confirmar Format = JSON.
  • Confirmar URL exacto (sem espaços, sem trailing slash extra).
  • Webhook Signing Secret no integrador tem de bater com o "Your webhooks will be signed with: ..." do Shopify.

"Develop apps" não aparece no admin

  • Conta usada não é Store owner nem tem permissão Develop apps.
  • Store owner: Settings → Users and permissions → editar utilizador → marcar Develop apps.
  • Ou pedir ao Store owner para criar a app e partilhar o token.
